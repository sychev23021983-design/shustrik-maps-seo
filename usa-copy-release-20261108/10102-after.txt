<h2>OBJ levels of detail</h2>
<p>Choose from the supplied LOD100, LOD50 and LOD25 folders. Compare the versions in your software and select the mesh that suits your project. Check the imported geometry, units and material paths before building a scene.</p>
<h2>Texture files</h2>
<p>The archive contains TIF files named <code>Mat_0.tif</code> and <code>Mat_1.tif</code> in the LOD100 and C4D texture folders. The C4D folder also contains <code>plan.png</code>. Review the textures in your software to select the appearance you need.</p>
<h2>Listed mesh specifications</h2>
<p>The product listing describes an Albers Conic model with triangular polygon geometry, an open base and a frontal UV map. The listed C4D dimensions are 453.199 × 283.477 × 8.903 mm.</p>
<p>These are listing specifications. Check the selected file's dimensions, geometry and texture setup when preparing your project.</p>

<h2>Questions before purchase</h2>
<h3>Do I need to request the OBJ version separately?</h3>
<p>No. The package includes OBJ files in the LOD100, LOD50 and LOD25 folders.</p>
<h3>Are STL and FBX files included?</h3>
<p>The supplied model formats are C4D and OBJ. If you need a different format, confirm the requirements before purchasing.</p>
<h3>Which textures accompany the models?</h3>
<p>The LOD100 and C4D folders contain <code>Mat_0.tif</code> and <code>Mat_1.tif</code>. The C4D folder also contains <code>plan.png</code>.</p>
